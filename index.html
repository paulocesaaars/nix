Instalação

Pronto para começar?

Você precisa de um vault do Obsidian e de um sistema compatível. O binário da release já inclui o runtime: não é necessário instalar Python.

Disponível para Windows amd64, Linux amd64 ou arm64 e macOS Apple Silicon. A primeira sincronização baixa o modelo padrão, de cerca de 220 MB.

irm https://raw.githubusercontent.com/paulocesaaars/nix/main/install.ps1 | iex

Depois da instalação, abra um novo terminal. Ver instruções completas ↗

Alternativa de instalação

Quando a empresa bloqueia o executável

Se o executável, o PowerShell ou os downloads do instalador estiverem bloqueados, use o código-fonte com Python no Git Bash. Essa opção não instala o nix.exe.

01
Baixe o código

Na última release ↗, baixe Source code (zip). Se o GitHub estiver bloqueado nessa máquina, baixe em outra e copie o arquivo.

02
Descompacte e instale

Abra o Git Bash na pasta descompactada. Com Python 3.11 ou superior, execute:

python scripts/bootstrap.py --vault "C:/Obsidian/MeuVault"

Troque o caminho pelo seu vault e use barras /. Sem --vault, o instalador pergunta o caminho. O pip precisa alcançar o PyPI; a primeira sincronização ainda baixa o modelo.

03
Registre o cliente MCP

Aponte o comando para o Python do ambiente criado e passe -P -m nix como argumentos. Ajuste o caminho à pasta onde você descompactou o projeto:

{
 "mcpServers": {
   "nix": {
     "command": "C:/Git/nix/.venv/Scripts/python.exe",
     "args": ["-P", "-m", "nix"]
   }
 }
}

Abra um novo terminal e execute nix doctor. Se python não existir no Git Bash, tente py ou python3.

Depois de instalar

Do vault à primeira busca.

01
Configure seu vault

O instalador inicia a configuração. Informe o caminho para seu vault quando solicitado.

02
Confira e sincronize

Em um novo terminal, rode nix doctor e depois nix sync.

03
Conecte seu cliente MCP

Registre o Nix no seu agente e recarregue os servidores MCP. Use nix doctor para encontrar o caminho do comando.

Explore o Nix

Mais possibilidades para seu conhecimento.

O Nix oferece ferramentas para trabalhar com suas notas e administrar o ambiente local.

VAULTS

Até cinco vaults

Cadastre vaults nomeados e busque em um, em vários ou em todos. Cada escrita acontece em um único vault.

INTERFACE LOCAL

Administre pelo navegador

Execute nix ui para consultar notas, sincronizar, diagnosticar e configurar o Nix na sua máquina.

SESSÕES

Continue em outro agente

Ative o recurso opcional de sessões e instale hooks por projeto para registrar o trabalho e preparar um handoff.

SINCRONIZAÇÃO

Você escolhe quando

Alterações externas entram no índice com nix sync; escritas feitas pelo Nix atualizam o índice na operação.

PROTEÇÃO

Escrita com cuidado

Operações destrutivas exigem confirmação e versões anteriores são guardadas em backups antes de sobrescrever.

MODELOS

Escolha o embedding

O padrão é o modelo local lulu. O spitz é uma alternativa maior; trocar de modelo exige nix sync --full.

Desinstalação

Remova a instalação quando precisar.

Escolha o comando correspondente à forma como instalou. O vault do Obsidian não é alterado.

01
Instalado pelo PowerShell

Baixe e execute o desinstalador no PowerShell:

irm https://raw.githubusercontent.com/paulocesaaars/nix/main/uninstall.ps1 -OutFile "$env:TEMP\uninstall-nix.ps1"
& "$env:TEMP\uninstall-nix.ps1"

Responda s à confirmação.

02
Linux ou macOS
curl -fsSL https://raw.githubusercontent.com/paulocesaaars/nix/main/uninstall.sh | sh
03
Instalado a partir do código ou zip

Na pasta descompactada ou do clone, execute:

python scripts/uninstall.py

Use --yes para dispensar a confirmação e --keep-data para preservar settings.db e o índice. Abra um novo terminal e remova também o servidor Nix da configuração MCP do editor. O cache compartilhado do modelo pode permanecer.
